# Developer sources and patches

Player releases contain three uploaded files: the application ZIP,
READ-ME-FIRST.txt and SHA256SUMS-community.txt. Technical files live in this
repository, keeping the download page focused on installation. GitHub also adds
two automatic source-archive links; those are generated by GitHub.

## Exact source for the community preview

```sh
git clone --recursive --branch v0.4.0-preview.1 https://github.com/xPXavierx/gow3-macos-arm64.git
cd gow3-macos-arm64
```

The recursive clone includes the pinned submodule sources. GitHub's automatically
generated source ZIP/tar archives do not include submodule contents.

- [Build and preparation guide](COMMUNITY.md#packaging-from-source-maintainers-only).
- [Measured validation](COMMUNITY_VALIDATION.md) and [machine-readable results](community-validation.json).
- [ARM64 recompiler patch](../aot/bloodborne-recomp-arm64.patch) and [pinned AOT source setup](../aot/README.md).
- [MoltenVK patches and build guidance](../native/FRAME_PACING.md).
- [Full native port compared with the pinned upstream base](https://github.com/xPXavierx/gow3-macos-arm64/compare/7180a7bafa51afbe991523f6392f69ea1cf03e1e...v0.4.0-preview.1).
  GitHub also provides this comparison as a [patch](https://github.com/xPXavierx/gow3-macos-arm64/compare/7180a7bafa51afbe991523f6392f69ea1cf03e1e...v0.4.0-preview.1.patch).

Game dumps, locally prepared images/C/libraries, saves and shader caches are not
part of this source repository. Preserve the retained dependency licenses and
source revisions when building or redistributing the runtime.
